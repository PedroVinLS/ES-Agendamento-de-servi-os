# Plataforma de Agendamento de Serviços

## 📌 Descrição do Projeto

Este projeto tem como objetivo desenvolver uma plataforma de agendamento de serviços, voltada para negócios como barbearias, estúdios ou prestadores de serviços em geral.

A aplicação permitirá que clientes escolham serviços, visualizem horários disponíveis e realizem agendamentos, enquanto os profissionais poderão gerenciar sua agenda semanal de forma organizada e eficiente.

Este projeto está sendo desenvolvido como parte da disciplina de Engenharia de Software, seguindo boas práticas de organização, versionamento e evolução incremental.

## 🎯 Objetivo

Criar um sistema que:

Facilite o agendamento de serviços por clientes
Permita o gerenciamento de horários por profissionais
Garanta consistência e integridade dos dados de agenda
Evite conflitos de horários

## ⚙️ Funcionalidades Iniciais (MVP)
Cadastro de clientes e profissionais
Cadastro de serviços
Visualização de agenda semanal
Agendamento de horários
Cancelamento de agendamentos

## 🛠️ Tecnologias (proposta inicial)

(Pode ser ajustado conforme evolução do projeto)

Backend: Node.js
Frontend: HTML, CSS, JavaScript
Banco de Dados: MySQL
Versionamento: Git e GitHub
