# Como contribuir

## Ramos
- `feat/<descricao-curta>` para funcionalidade nova
- `fix/<descricao-curta>` para correção
- `docs/<descricao-curta>` para documentação
- Criados sempre a partir do `main` atualizado

## Commits
- Conventional Commits: `tipo(escopo): resumo no imperativo`
- Corpo explicando o porquê, quando a mudança não for óbvia
- Referência à issue: `Closes #<numero>`

## Pull requests
- Um item de backlog por PR
- Descrição com o que muda e como testar
- Revisão de uma pessoa diferente do autor, em até 24 horas
- Autor integra depois da aprovação e remove o ramo
